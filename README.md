# Nachiketa Jha — Personal Portfolio

Minimal personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. Published through GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

The site is configured for GitHub Pages from the `main` branch.

## Notes

- No build step or framework required.
- Responsive layout and reduced-motion support.
- Project descriptions distinguish implemented work from proposals and concepts.
- Update social links and project entries in `index.html` as your work evolves.
